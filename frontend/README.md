# Full-Stack Internship Project

## Fundamentals and Setup

This project was created as part of my Full-Stack Development Internship. The objective of this project is to set up a complete development environment, understand the basic structure of a full-stack application, configure frontend and backend technologies, and verify that the development environment is working correctly.

## Project Objective

The main objective was to create a simple Hello World full-stack project while learning the fundamentals of frontend and backend development, project organization, and development tools.

## Technologies Used

* React
* Vite
* JavaScript
* Node.js
* Express.js
* CORS
* dotenv
* Git
* GitHub
* Visual Studio Code

## Frontend

The frontend was developed using React and Vite. A simple Hello World page was created to verify that the React development environment was configured correctly.

The frontend runs on:

`http://localhost:5173`

## Backend

The backend was developed using Node.js and Express.js. A basic API endpoint was created to verify that the backend server is working correctly.

The backend runs on:

`http://localhost:5000`

The root endpoint returns:

```json
{
  "message": "Backend is running successfully!"
}
```

## Hello World Verification

The frontend displays:

**Hello World!**

**My Full-Stack Internship Project is Working.**

This confirms that the React frontend is running successfully.

The backend response was also tested successfully through the browser.

## Development Environment

The development environment was configured using Visual Studio Code, Node.js, npm, React, Vite, and Express.js. Git and GitHub are used for version control and project sharing.

## Learning Outcomes

Through this project, I learned how to:

* Set up a development environment.
* Create a React application using Vite.
* Create a Node.js and Express backend.
* Organize a full-stack project into frontend and backend directories.
* Run frontend and backend development servers.
* Test a backend API endpoint.
* Use Git and GitHub for version control.
* Document a software project using README.md.

## Conclusion

The Fundamentals and Setup project successfully established the basic foundation required for full-stack development. Both the frontend and backend applications were configured and tested successfully. The project structure provides a starting point for developing more advanced full-stack applications during the internship.
